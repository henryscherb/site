# henryscherb.com

Personal portfolio site for Henry Scherb. Plain static HTML, no build step.

- `index.html` – Profile Overview
- `consulting.html`, `advocacy.html`, `startup.html`, `venture.html`, `academics.html` – section pages
- `assets/` – photo, résumé PDF (no contact details) and social preview image
- `vercel.json` – serves pages at clean URLs (e.g. `/consulting`)

Deployed on Vercel; every push to `main` goes live automatically.
